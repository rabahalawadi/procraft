# Fullscreen Plugin for ProCraft

This plugin adds complete fullscreen management and toggling capabilities to ProCraft.

## Features
- **Fullscreen Mode Toggle**:
  - Switch smoothly between standard windowed mode and fullscreen display.
  - Trigger fullscreen toggle directly from the plugin card in **Actions -> Prefs -> Plugins -> Fullscreen -> Toggle Fullscreen**.
- **Exclusive Fullscreen Option**:
  - Toggle between **Exclusive Fullscreen** (highest monitor refresh rate, minimal latency) and standard borderless windowed fullscreen.
- **Keyboard Shortcuts**:
  - Support for industry standard **F11** and **Alt+Enter** keyboard shortcuts to toggle fullscreen on and off.
  - Can be toggled on/off independently via the plugin control switch.

## How to Install / Import
1. Open **ProCraft**.
2. Open any canvas, or open the Gallery.
3. Open the **Actions** menu (wrench icon in top bar) -> **Help / Prefs** -> **Plugins**.
4. Tap **Import Plugin** and select `fullscreen.procraft-plugin` from this folder.
5. The **Fullscreen** plugin will now appear in your plugins list.

## Plugin Controls & Actions
- **Enable fullscreen features**: Master switch enabling/disabling fullscreen capability.
- **Exclusive fullscreen (max refresh rate)**: When enabled, runs in exclusive mode for highest monitor refresh rate.
- **Keyboard shortcuts (F11 / Alt+Enter)**: Allows toggling fullscreen via keyboard shortcuts.
- **Toggle Fullscreen**: Action button to immediately toggle fullscreen on or off.
