# macOS Top Bar Plugin for ProCraft

This plugin adds the macOS-style top bar with traffic light window controls (Close, Minimize, Maximize) to ProCraft.

## Features
- **Enabled (macOS Style)**:
  - Frameless / borderless window.
  - Sleek traffic light window control buttons (Close, Minimize, Maximize) with hover glyphs on the top left.
  - Draggable top bar and gallery / tool headers with double-click to maximize/restore.
  - Rounded top corner aesthetics (12pt radius).
- **Disabled (Default Windows Style)**:
  - Standard native Windows title bar and window decorations.
  - Native Windows minimize, maximize, and close controls in the top-right corner.
  - Full native window snapping and window dragging.
  - Standard default layout and margins.

## How to Install / Import
1. Open **ProCraft**.
2. Open any canvas, or open the Gallery.
3. Open the **Actions** menu (wrench icon in top bar) -> **Help / Prefs** -> **Plugins**.
4. Tap **Import Plugin** and select `macos-topbar.procraft-plugin` from this folder.
5. The **macOS Top Bar** plugin will now appear in your plugins list.

## How to Toggle
- You can turn the plugin **ON** or **OFF** at any time from the Plugins page using its master toggle switch or its "macOS style top bar" control switch.
- When enabled, ProCraft instantly switches to the macOS top bar without needing a restart.
- When disabled, ProCraft restores the default Windows top bar and title decorations.
